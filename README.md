# 日常消費記帳本 (Expense Tracker)

一個專為個人日常理財打造的現代化記帳網頁，支援**「食、衣、住、行、育、樂」**六大生活消費分類，即時呈現當月總消費與消費比例圓餅圖，支援快速分月切換與查詢，並可無縫串接 **Google 雲端表單 (Google Forms)** 與 **Google 試算表 (Google Sheets)** 達成雲端備份與多裝置同步。

---

## 🌟 主要功能特點

1. **六大生活分類**：
   - 🍜 **食**：餐飲、三餐、外送、下午茶
   - 👕 **衣**：服飾、鞋包、配件
   - 🏠 **住**：房租、水電費、瓦斯、生活雜物
   - 🚗 **行**：捷運公車通勤 (TPASS)、汽機車加油、停車費、計程車
   - 📚 **育**：書籍、線上課程、技能進修、學雜費
   - 🎮 **樂**：電影、遊戲、露營、旅遊度假、聚會
2. **智慧月度統計與圓餅圖**：
   - 頂部月份導覽：支援「上個月」、「下個月」、「回到本月」及自訂年月選擇。
   - 關鍵指標卡片：即時計算當月總支出、記帳筆數、當月最高開銷類別。
   - 可視化圓餅圖 (Chart.js)：支援「環形圖」與「實心圓餅圖」自由切換，懸停即時顯示類別金額與佔比。
   - 右側進度條：直觀呈現各類別花費與百分比。
3. **明細檢索與過濾**：
   - 依日期降序排序列出當月所有開銷。
   - 支援依類別（食/衣/住/行/育/樂）篩選或即時關鍵字搜尋品項。
4. **Google 雲端雙向串接**：
   - **方案 A (推薦 - Google Apps Script)**：網頁可直接即時讀取試算表全部歷史紀錄，也可即時新增寫入，跨手機/電腦皆能同步。
   - **方案 B (Google Forms 方式)**：只需貼上表單回應網址與 Entry ID，每次記帳自動 POST 到 Google 雲端表單，免寫後端。
   - **本機模式 (LocalStorage)**：即使不設定 Google 帳號，也能在瀏覽器完整使用並支援 JSON 備份匯出。

## 🚀 如何啟動使用

### 方法 1：直接開啟
在 Windows 檔案總管中，直接雙擊 `d:\antigraverty\expense-tracker\index.html`，用 Chrome、Edge 等瀏覽器開啟即可！

### 方法 2：使用本機伺服器預覽（可選）
在命令提示字元或 PowerShell 輸入：
```powershell
cd d:\antigraverty\expense-tracker
python -m http.server 8080
```
接著在瀏覽器打開：`http://localhost:8080` 即可使用。

## ☁️ Google 雲端串接教學

### 方案 A：Google Apps Script (雙向同步，最推薦！)

此方式可讓網頁**「自動讀取」**試算表過去的所有資料繪製圓餅圖，且每次新增都會**「即時寫入」**試算表：

1. 開啟 [Google 雲端硬碟](https://drive.google.com/)，新增一份「Google 試算表」。
2. 點擊頂部選單的 **「擴充功能」 -> 「Apps Script」**。
3. 將原本裡面的程式碼清空，複製本專案中的 `google-apps-script.js` 內容貼上。
4. 點擊右上角的 **「部署」 -> 「新增部署作業」**：
   - **齒輪圖示 (選取類型)**：選擇「網頁應用程式 (Web App)」。
   - **說明**：記帳 API。
   - **執行身分**：我 (你的 Google 帳號)。
   - **誰可以存取**：**「任何人 (Anyone)」** *(重要！必須選任何人，網頁才有權限存取)*。
5. 點擊「部署」，依照畫面引導授權 Google 存取試算表。
6. 複製畫面上的**「網頁應用程式網址 (URL)」**（格式類似 `https://script.google.com/macros/s/AKfycb.../exec`）。
7. 回到記帳網頁，點選右上角齒輪設定圖示，貼上該網址並點擊「儲存設定」即可！

---

### 方案 B：Google 雲端表單 (Google Forms 快速提交)

如果你只需要送出時自動寫入 Google 表單（Google 表單會自動彙整成試算表）：

1. 到 [Google Forms](https://forms.google.com/) 建立一份新表單。
2. 建立以下 4 個問題（建議順序如下）：
   - `消費日期` (日期類型)
   - `消費類別` (單選題：食、衣、住、行、育、樂)
   - `金額` (簡答題，驗證選「數字」)
   - `備註說明` (簡答題)
3. 點選表單右上角的三個點 `⋮` -> **「取得預先填入的連結」**。
4. 隨意在 4 個題目填寫測試文字，點擊「取得連結」並複製。
5. 觀察複製出來的網址：
   - 將最後面的 `prefill` 改成 `formResponse`，即為「表單回應網址」。
   - 從網址參數中找出各題目的代碼，例如 `entry.123456789=...`。
6. 回到記帳網頁齒輪設定中的「方案 B」，填入對應的 Entry ID 與表單回應網址即可！

## 🚀 上傳至 GitHub Pages (免重複設定技巧)

上傳到 GitHub Pages 後，如果只在瀏覽器介面手動貼網址，設定只會儲存在「該瀏覽器的 LocalStorage」中。若您換了手機、用 LINE 內嵌瀏覽器開啟或清除快取，就必須重新設定。

### 🌟 終極一勞永逸做法：填寫 `config.js`

1. 打開專案中的 `config.js`。
2. 將您的 Google Apps Script 網址填入 `gasUrl`：
   ```javascript
   window.DEFAULT_CONFIG = {
     gasUrl: "https://script.google.com/macros/s/AKfycb.../exec",
     ...
   };
   ```
3. 上傳（Push）到 GitHub。
4. **完成！** 無論在任何手機、平板、電腦打開您的 GitHub Pages 網址，系統都會**自動連線並在背景同步最新試算表資料**，完全不需要再次輸入設定！
